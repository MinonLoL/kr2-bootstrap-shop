## Описание проекта

**Goldabook** — современный адаптивный сайт литературного сообщества и книжного клуба. Проект разработан на **HTML5**, **CSS3**, **JavaScript (ES6+)** и **Bootstrap 5.3**. Он помогает любителям чтения находить выдающиеся книги по жанрам и рейтингу читателей, знакомиться с отзывами резидентов клуба, изучать план дискуссий и записываться на регулярные очные и онлайн-встречи.

### Основные разделы сайта:
1. **Главная (`index.html`)** — представление клуба, ценности и миссия с векторной графикой, интерактивная карусель подборки месяца с контрастными контролами, блок доверия с реальными фотографиями резидентов и карточки ближайших митапов.
2. **Каталог книг (`catalog.html`)** — адаптивная 12-колоночная сетка карточек книг с живым поиском, фильтрацией по жанрам (Классика, Фантастика, Антиутопии), сортировкой по рейтингу и интерактивной пагинацией на 3 страницы (9 произведений).
3. **Карточка книги (`product.html`)** — детальное описание романа «Мастер и Маргарита», обложка, рейтинг, интерактивные вкладки (темы дискуссии, отзывы читателей с фото, цитаты с копированием в буфер обмена), таблица характеристик издания и блок частых вопросов (Accordion).
4. **Встречи клуба и запись (`order.html`)** — подробный календарь событий и полноценная форма записи на литературные встречи со всеми валидируемыми полями и интерактивным калькулятором.
5. **Контакты (`contacts.html`)** — адрес лофта читальни на Покровке, часы работы, интерактивная карта, ссылки на соцсети, форма обратной связи и FAQ клуба.
6. **Встречи (`meetings.html`)** — быстрый алиас/редирект для раздела встреч.

## Используемые технологии
- **HTML5:** семантическая структура (`header`, `nav`, `main`, `section`, `article`, `footer`, `blockquote`).
- **Bootstrap 5.3.3:** 12-колоночная сетка, utility-классы и интерактивные компоненты.
- **CSS3 / `custom.css`:** трёхслойная система дизайн-токенов, полноценная светлая и тёмная темы без эффекта FOUC (белого мерцания), соблюдение стандартов контрастности WCAG AAA, микроанимации при наведении и состояния `:focus-visible`.
- **JavaScript (ES6+ / `app.js`):** переключение и сохранение темы в `localStorage`, интерактивный список чтения («Закладки»), живой поиск и фильтрация каталога, копирование цитат с Toast-уведомлением, калькулятор стоимости и генератор билетов.
- **Графика и медиа:** качественные фотографии резидентов и лофта в блоке доверия, векторные SVG-обложки книг и авторские пиктограммы.
- **Git & GitHub:** контроль версий, ветки и фиксация этапов разработки.

## Способ подключения Bootstrap (Выполнение повышенного требования)

В соответствии с методическими указаниями, в проекте выполнено требование автономности: **Bootstrap подключён локально, без опоры на сторонние CDN**.

Файлы фреймворка размещены внутри репозитория в папке `vendor/bootstrap/`:
- `vendor/bootstrap/css/bootstrap.min.css` — скомпилированные и минифицированные стили Bootstrap 5.3.3;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — скомпилированный скрипт интерактивных компонентов Bootstrap (включая Popper.js).

### Порядок подключения в `<head>`:
```html
<!-- 1. Локальные стили фреймворка Bootstrap -->
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">

<!-- 2. Собственные переопределения и стили проекта (строго ПОСЛЕ Bootstrap) -->
<link rel="stylesheet" href="css/custom.css">
```

### Подключение скриптов перед `</body>`:
```html
<!-- Интерактивный Bootstrap JS Bundle -->
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<!-- Логика интерактивности приложения -->
<script src="js/app.js"></script>
```

Такой способ гарантирует полную автономность проекта, независимость от сетевых сбоев и высокую скорость загрузки страниц.

## Реализованные компоненты Bootstrap

| Компонент Bootstrap | Назначение в проекте Goldabook |
| :--- | :--- |
| `container`, `row`, `col-*` | 12-колоночная адаптивная сетка (`col-12`, `col-md-6`, `col-lg-4` и др.), гибкие отступы `g-4`, `g-3` |
| `navbar` | Адаптивная шапка с логотипом, гамбургер-меню для мобильных, активными ссылками и `dropdown` |
| `card` | Карточки произведений, карточки преимуществ, календарь встреч, контейнеры форм и отзывов |
| `btn` | Кнопки действий: `.btn-gold`, `.btn-outline-gold`, `.btn-primary`, `.btn-outline-dark`, `.btn-sm`, `.btn-lg` |
| `badge` | Метки статуса книг и встреч: «Золотая коллекция», «Хит месяца», «Выбор клуба», «Офлайн / Zoom» |
| `alert` | Информационные сообщения пользователю (`role="alert"`): предупреждения, даты встреч, подсказки |
| `modal` | Всплывающее окно быстрой записи (`#quickOrderModal`) с формой бронирования места и валидацией |
| `form-control` | Поля ввода: текстовые (`name`), электронная почта (`email`), телефон (`tel`), отзывы (`textarea`) |
| `form-select` | Выпадающие списки выбора жанров, сортировки, встреч и формата участия |
| `input-group` | Поле телефона с префиксом `+7` и поисковое поле с пиктограммой |
| `form-check` | Чекбоксы согласия на обработку данных и подписки на дайджест клуба |
| `table` + `table-responsive` | Таблица параметров издания и регламента дискуссии на странице книги |
| `accordion` | Раскрывающиеся секции регламента, FAQ по книге и общих вопросов клуба |
| `carousel` | Слайдер подборки книг месяца на главной странице с индикаторами и высококонтрастными стрелками |
| `nav-tabs` | Интерактивные вкладки в карточке книги (темы дискуссии / отзывы с фото / цитаты) |
| `pagination` | Интерактивная 3-страничная пагинация в каталоге книг с динамическим отображением |
| `breadcrumb` | Хлебные крошки для навигации на всех внутренних страницах |

## Самостоятельные доработки для получения максимального балла (5 из 5)

В соответствии с критериями повышенного и высокого уровня (требования к КР №3):
1. **Локальный вендор:** исключена зависимость от CDN, библиотека развернута в `vendor/bootstrap/`.
2. **Расширенный состав страниц:** кроме 4 базовых страниц созданы полноценная страница контактов (`contacts.html`), страница расписания встреч с интерактивным калькулятором (`order.html`) и карточка книги (`product.html`).
3. **Комплекс дополнительных интерактивных компонентов:** интегрированы `carousel` (с кастомными круглыми кнопками 50px и доступностью WCAG AAA), `nav-tabs`, `accordion`, `pagination`, `breadcrumb`, `table-responsive`.
4. **Богатый каталог и фильтрация:** каталог включает 9 разноплановых книг с живым поиском без перезагрузки, фильтрацией по жанрам и динамической пагинацией.
5. **Профессиональный визуал:** блок доверия оформлен реальными качественными фотографиями резидентов и лофта, а для карточек преимуществ созданы авторские векторные пиктограммы.
6. **Выверенный `custom.css` и дизайн-система:** стилизована тёплая литературная эстетика (золото, грифель, кофе), hover-анимации подъёма карточек, тени и контраст.
7. **Поддержка доступности (WCAG) и адаптивность:**
   - Проверены брейкпоинты: 360–430px (смартфон), 768px (планшет), 1024–1440px (десктоп).
   - Все поля форм имеют строгие связи `<label for="...">` с `id`.
   - Внедрён видимый фокус клавиатуры `:focus-visible` (золотистый контур с тенью).
   - Ссылка быстрой навигации `.skip-link` для скринридеров.
   - Осмысленные атрибуты `alt` для всех изображений.

## Проверка адаптивности

Страницы проверены через браузерные инструменты разработчика (DevTools):
- **Мобильные устройства (360–430px):** элементы перестраиваются в 1 колонку (`col-12`), меню складывается в гамбургер, формы и модальные окна не выходят за ширину экрана, горизонтальная прокрутка отсутствует.
- **Планшеты (768px):** сетка переходит в двухколоночный режим (`col-md-6`), навигация остаётся компактной.
- **Десктоп (1024–1440px):** трёхколоночная сетка каталога (`col-lg-4`), полноразмерный navbar, развёрнутые hero-блоки.
